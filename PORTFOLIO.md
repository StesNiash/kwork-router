# PORTFOLIO — kwork-router

## Кейс 1. Hermes Agent на VPS

**Задача.** Развернуть персонального AI-агента на чистом Ubuntu VPS, подключить Telegram и оставить владельцу рабочую инструкцию.

**Что сделано.**

- Docker Compose с официальным образом Hermes.
- `.env` с правами `600`, без секретов в git.
- Автозапуск и healthcheck.
- Backup каталога данных и команда восстановления.
- Проверка на чистом Ubuntu 22.04/24.04.
- Честный список ограничений: чужие API-ключи, лимиты модели, стоимость трафика.

**Результат для покупателя.** Один `install.sh`, понятный `README.md`, healthcheck и возможность отката. Не «магия в чате», а воспроизводимый установщик.

## Кейс 2. Парсер → CSV (демо-контур)

**Задача.** Собрать карточки с пагинацией и отдать таблицу, которую можно открыть в Excel.

**Что сделано.**

- Парсер на тестовом каталоге, без обхода защит.
- Нормализация полей и удаление дублей.
- Выгрузка CSV/XLSX.
- Отчёт: сколько страниц обработано, где были ошибки.
- Повторный запуск не ломает уже собранные данные.

**Результат для покупателя.** Видно, что именно попадёт в таблицу, ещё до оплаты доступа к реальному сайту.

> Это демо-кейсы. Реальные клиентские данные и секреты в репозиторий не попадают.
