# kwork-router

Единый репозиторий карточек Kwork: здесь лежат описания, цены, FAQ и промпты обложек. Демо-репозитории `kwork-*` — только рабочие доказательства, на которые ссылается эта таблица.

Сайт не нужен. Основной вход — `README.md` и файлы в `cards/`.

## Как добавить или обновить карточку

1. Создайте/измените файл в `cards/`.
2. Обновите строку в таблице выше.
3. Обновите запись в `data/services.json` и ссылку на демо.
4. В демо-репозитории оставьте только короткую ссылку на карточку, без копии текста.
5. Запустите тесты.

## Проверка

```powershell
python -m unittest discover -s tests -v
```

Тесты проверяют:
- обязательные поля таблицы и допустимые статусы;
- наличие файлов карточек для готовых направлений;
- ссылки на GitHub-демо;
- наличие промпта обложки в каждой карточке;
- отсутствие сайтовых файлов и секретов.

## Карточки

Формат полей и лимиты — в [FORMAT.md](FORMAT.md), полное дерево рубрик — в [TAXONOMY.md](TAXONOMY.md).

В каждом `cards/*.md` есть:

- `## Название`;
- `## Рубрика` → `## Подрубрика` → `## Тип` → `## Вид`;
- `## Языки` — для вида «Написание и доработка»;
- `## Обложка (660×440, 3:2)`;
- `## Описание`;
- `## От покупателя нужно`;
- `## Стоимость и опции`;
- `## Дополнительные опции`;
- `## FAQ` в формате вопрос-ответ.

## Обложки

Обложка — **660 × 440 px, 3:2**, с крупным текстом об предложении. В каждом `cards/*.md` есть:

- точный крупный текст;
- промпт для ChatGPT / Gemini с типографикой;
- негативный промпт;
- для Hermes — правила по исходникам и скриншотам.

## Правила

- Детали карточки хранятся только здесь; демо-репозитории не дублируют описание.
- Карточка не считается готовой, пока нет рабочего демо и тестов.
- Цены и сроки — черновые, не публичная оферта.
- В репозитории нет клиентских токенов, ключей и персональных данных.
