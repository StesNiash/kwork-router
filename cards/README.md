# Карточки Kwork

Единое место для текстов карточек. Демо-репозитории `kwork-*` содержат только код, тесты и ссылку сюда.

## Формат

Полные требования — в [../FORMAT.md](../FORMAT.md), дерево рубрик — в [../TAXONOMY.md](../TAXONOMY.md).

- `NN-name.md` — одна карточка;
- `Название`, `Рубрика`, `Подрубрика`, `Тип`, `Вид`;
- `Языки` — только для вида «Написание и доработка»;
- обложка **660×440, 3:2** с крупным текстом и промптом;
- `Описание`, `От покупателя нужно`;
- `Стоимость и опции` и `Дополнительные опции`;
- FAQ в конце.

## Правила

- В демо-репозиториях нет копий описания — только ссылка на этот файл.
- `data/services.json` хранит краткую запись и путь `cards/...`.
- При смене цены или scope сначала правится карточка здесь.
- Промпт обложки обязан содержать крупный текст, а не только иллюстрацию.
- Если модель искажает кириллицу, генерируется фон без текста, текст накладывается в редакторе.

## Статусы

- `active` — карточка опубликована;
- `ready` — демо готово, карточка не опубликована;
- `planned` — репозитория ещё нет.
